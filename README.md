# Flight Data Recorder for X-Plane 12

## Goals

The function of this X-Plane 12 plugin is to record specific flight parameters and output a GeoJSON file. This file will contain all the flight parameters for analysis, visualization, or processing by third-party software.

## Tracking data

- Aircraft ICAO
- Aircraft name
- Number of engines
- Type of engines
- Total power
- Power per engine
- Timestampe UTC
- Longitude
- Latitude
- Barometric altitude
- Height above ground
- QNH
- Indicated air speed
- True air speed
- Ground speed
- Vertical speed
- Cap (DEG mag)
- heading (DEG true)
- route mag (DEG mag)
- route true (DEG true)
- pitch (DEG)
- bank (DEG)
