# Flight Data Recorder for X-Plane 12

## Goals

The function of this X-Plane 12 plugin is to record specific flight parameters and output a GeoJSON file. This file will contain all the flight parameters for analysis, visualization, or processing by third-party software.

## Tracking data

Aircraft ICAO
Aircraft name

timestampe (LOCAL)
timestampe (ZULU)

longitude (DMS)
latitude (DMS)
altitude mean sea level (MSL)
altitude above ground level (AGL)

indicated air speed (IAS)
ground speed (GS)
vertical speed (FPM)
cap (DEG mag)
heading (DEG true)
route mag (DEG mag)
route true (DEG true)

pitch (DEG)
bank (DEG)
total power (HP)
QNH
